# 同梱フォントのライセンス

satori へ渡す TTF をこのディレクトリへ置いている。いずれも SIL Open Font License 1.1。

| ファイル              | 書体           | ライセンス                                                  |
| --------------------- | -------------- | ----------------------------------------------------------- |
| `Orbitron-*.ttf`      | Orbitron       | SIL OFL 1.1（<https://fonts.google.com/specimen/Orbitron>） |
| `JetBrainsMono-*.ttf` | JetBrains Mono | SIL OFL 1.1（<https://www.jetbrains.com/lp/mono/>）         |

日本語（Noto Sans JP）はバンドルせず、実行時に Google Fonts のサブセットを取得する。Noto Sans JP も SIL OFL 1.1。
